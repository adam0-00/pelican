Projets d'applications web

Application Web & BDD Projet 1

🏨 Gestion des salariés de l'hôtel Chambord

Objectif : Développer une application web en PHP, connectée à une base de données MySQL, permettant de gérer les salariés d'un hôtel fictif (affichage, statistiques, opérations CRUD).

Ce qui a été réalisé :
  • Connexion sécurisée PDO (requêtes préparées, gestion des erreurs)
  • Architecture modulaire (séparation de la logique métier et de l'affichage)
  • Affichage de la liste des salariés sous forme de tableau Bootstrap
  • Calculs statistiques (effectifs, salaires moyen/min/max, répartition par service via COUNT, AVG, GROUP BY)
  • Interface CRUD complète (Ajout, Modification, Suppression via formulaires)
  • Implémentation du pattern PRG (Post/Redirect/Get) pour éviter la duplication des données
PHP MySQL PDO HTML / CSS Bootstrap

API REST & Web Projet 2

🎬 MovieDB (utilisation d'une API REST)

Objectif : Créer une interface web permettant de consulter les films populaires, les mieux notés, les genres, les détails d'un film et les acteurs via l'API REST de TMDB (The Movie Database).

Ce qui a été réalisé :
  • Consommation de l'API TMDB via des requêtes HTTP GET (ex: fonction popularMovies())
  • Conversion et traitement de la réponse JSON en tableau PHP avec json_decode()
  • Galerie de cartes Bootstrap dynamiques pour l'affichage des films (affiches + titres)
  • Mise en place d'un système de recherche et de filtres par genre et par acteur
PHP API REST (TMDB) JSON Bootstrap
